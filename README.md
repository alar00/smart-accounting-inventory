# 📊 نظام المحاسبة وإدارة المخزون والمستودعات الذكي (Smart Accounting & Inventory System)

نظام محاسبي ومخزني متكامل باللغة العربية يعمل **100% أوفلاين (بدون إنترنت)** على أجهزة الكمبيوتر والهواتف الذكية.

## ✨ أبرز مميزات النظام (22 شاشة محاسبية ومخزنية متكاملة)
1. **⚡ نقطة البيع السريعة (POS الكاشير):** دعم قارئ الباركود، حساب الباقي للعميل، وطباعة إيصال كاشير حراري 80mm أو فاتورة A4.
2. **🧾 فواتير المبيعات والمشتريات والمرتجعات:** نقداً، آجل، أو دفع جزئي مع توليد القيود المحاسبية وتحديث المخزون آلياً.
3. **👥 إدارة العملاء والموردين وأعمار الديون (CRM):** متابعة الديون المتأخرة، كشوفات الحساب التفصيلية، تحصيل/سداد فوري، ونسخ مطالبات واتساب.
4. **📋 شاشة الجرد الفعلي السريع للمخزون (Smart Stocktaking Sheet):** مقارنة الرصيد الدفتري بالفعلي المعدود مع دعم الباركود واعتماد قيود الفائض والعجز بضغطة زر.
5. **🏬 تعدد المستودعات والتحويل والتسوية المخزنية والأرصدة الافتتاحية.**
6. **🌳 شجرة الحسابات، دفتر اليومية، دفتر الأستاذ، ميزان المراجعة، قائمة الدخل، والميزانية العمومية.**
7. **🔐 حماية بكلمة مرور وسجل رقابة وتدقيق أمني (Audit Log) ونسخ احتياطي واستعادة شاملة.**
